# ALFERZA LIVE OFFICE

Aplicación web para monitorear en tiempo real la disponibilidad y presencia de los colaboradores de ALFERZA mediante integración con Microsoft Graph y Azure Entra ID.

## Funcionalidades

- Consulta de usuarios corporativos.
- Estado de presencia en tiempo real.
- Búsqueda rápida de colaboradores.
- Dashboard con indicadores de disponibilidad.
- Integración con Microsoft 365.
